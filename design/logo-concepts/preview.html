NexusChat Logo 概念稿

三套候选，同一个品牌底色（#6C5CE7 → #8E7BFF 渐变、#22D3EE 强调）。 右侧小尺寸列用来检查 16 / 32 / 48 px 下是否还认得出来 —— 这是图标最容易翻车的地方。

已採用方案 A。 矢量源檔在 design/logo/nexuschat.svg，各平台圖示由 tool/gen_app_icons.py 生成（python tool/gen_app_icons.py）， 已覆蓋 Android / iOS / macOS / Windows / Web 共 39 個檔案。 B、C 兩套保留在本頁作為設計紀錄。
方案 A · 已採用

Nexus 节点星网

Nexus＝连接点。中心青点是你的 DID，外围六点是网络中的其他节点，连线是消息路径，其中两点做成气泡形暗示对话。

优点

  • 最贴合「去中心化网络」这件事
  • 纯图形无文字，不受语言影响
  • 节点可复用成加载动画、空状态插图

风险

  • 细连线在 16px 会糊，需另做简化版（去掉连线、只留中心点 + 四点并加粗）
方案 B

护盾气泡

上缘是聊天气泡的圆角，下缘收成盾牌尖；锁孔以负形挖出，右上缘一道青弧代表加密环。

优点

  • 一眼看懂「加密聊天」，App Store 里分类辨识度最高
  • 小尺寸最稳：单一主体 + 粗轮廓，16px 仍清楚

风险

  • 与市面「盾牌 / 锁」类隐私 App 容易撞脸
  • 对「去中心化 / 钱包」那一层传达偏弱
方案 C

轨道 N

N＝NexusChat；倾斜的青色轨道环代表链上身份与多链网络，环被 N 覆盖处自然断开，形成前后层次。

优点

  • 品牌识别最强、最好记，扩展性最好（N 可单独当头像、favicon、社群帐号图）
  • 笔画粗，缩到 16px 仍然可读

风险

  • 字母标需要时间建立认知
  • 16px 必须去掉轨道环，只留 N
  • 若将来改名则失效
我的建议：选 C 作主标（图标 / 头像 / favicon 统一）， 把 A 的节点星网留作品牌辅助图形（下载页、加载动画、空状态插图）—— 兼顾识别度与「去中心化」的叙事。若你更想让用户在应用商店里一眼知道「这是加密聊天」，则选 B。

macOSmacos/Runner/Assets.xcassets/AppIcon.appiconset/圆角 + 内部留白约 80%
