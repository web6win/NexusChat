- CI fix (commit `abdf9f9`): Linux bundle upload failed with "No files were found:
  build/linux-bundle.tar.gz". Root cause: package step did `cd build/linux/x64/release/bundle` then
  `tar -czf ../../../linux-bundle.tar.gz .` — three `..` only climbs back to build/linux, not build/,
  so the tar landed at build/linux/linux-bundle.tar.gz (misplaced one level). Fixed by rewriting as
  `tar -czf build/linux-bundle.tar.gz -C build/linux/x64/release/bundle .` (explicit repo-root path).
  LESSON: avoid `cd` + relative `../` depth counting for archive outputs; use `tar -C` and an absolute
  / repo-root-relative output path instead. The Node-20-deprecation + punycode warnings in CI are
  harmless noise (actions run on Node 24 by default), not failures.
