  libp2p enrtree scheme) returns libp2p multiaddrs/ENRs for NODE-TO-NODE peer bootstrap — it is a

  advertise the REST port) cannot directly tell the app which node to connect to.

  - Layer 1 (ops only): enable --dns-discovery + --discv5-discovery on self-hosted nwaku relay

    still requires `application/json`.
